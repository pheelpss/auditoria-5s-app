# Ondexa Android 1.0.10+11

Flutter app for local 5S audits. It contains the approved questionnaires for all 31 areas (735 questions), local audit history, evidence capture, DOCX reports, and ZIP export of selected reports.

## Project structure

- `lib/` — application source.
- `test/` — Flutter regression tests.
- `assets/branding/` — app logo, icon, opening image and video.
- `scripts/` — checks and Android resource adjustments used by Codemagic.
- `docs/checklists_por_area_2026-10.json` — approved question catalog for the future Ondexa Desktop update.
- `codemagic.yaml` — Android release workflow.

The Android scaffold is generated by Codemagic during the build. It is intentionally not stored in this repository.

## Build from GitHub with Codemagic

1. Put the contents of this project at the root of the connected GitHub repository. Keep `pubspec.yaml` and `codemagic.yaml` at the root.
2. Run the **Ondexa Android Build** workflow.
3. Confirm the analysis and Flutter tests pass before downloading the APK from the build artifacts.

The workflow generates Android resources, runs `flutter analyze` and `flutter test`, then compiles the release APK. Use the same application ID and signing key as the installed app when replacing it; uninstalling the existing app can erase its local audit data.

## Photo quality

Capture and report generation preserve the resolution available from the image picker. Ordinary JPEG and PNG files are embedded byte for byte. Images with an EXIF rotation are converted to lossless PNG at their full pixel dimensions. Reports with photos can be larger. Existing DOCX files cannot regain detail already lost when they were generated.

## Important records

The area names, question counts, corrections and Desktop handoff are recorded in `docs/ATUALIZACAO_QUESTIONARIOS_2026-10.md` and `docs/checklists_por_area_2026-10.json`. The image validation and Codemagic update details are in `docs/ATUALIZACAO_FOTOS_1.0.10.md`.

Older release notes are retained in `docs/historico/` for reference.
