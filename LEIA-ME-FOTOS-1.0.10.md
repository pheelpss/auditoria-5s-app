# Ondexa 1.0.10 — atualização da qualidade das fotos

Envie o conteúdo desta pasta para a raiz do mesmo repositório GitHub e compile pelo workflow Ondexa Android Build no Codemagic. Substitua os arquivos correspondentes e inclua os novos arquivos. Não coloque a pasta Ondexa-App inteira dentro da raiz.

A captura deixa de solicitar compressão adicional e o DOCX preserva a resolução das fotos. JPEG/PNG comuns são incorporados byte a byte; correções de orientação usam PNG sem perdas. Os relatórios podem ficar maiores.

Os 21 testes de imagem e geração de relatórios executados passaram. A análise dos dois módulos alterados não encontrou problemas. Os testes de interface Flutter e a compilação Android serão executados no Codemagic.

As 31 áreas, as 735 perguntas e Teste Titan permanecem como na versão anterior.

Detalhes, resultados dos testes e registro para a atualização futura no PC: docs/ATUALIZACAO_FOTOS_1.0.10.md.
